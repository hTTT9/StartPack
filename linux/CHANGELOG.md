# Старт-пак для Linux — изменения

## 1.0.0
- Первая бета для Ubuntu, Debian, Fedora и РЕД ОС: пакеты .deb и .rpm и AppImage для любого Linux.
- Список программ с кнопками «Запустить» и «Остановить», «Запустить всё», запуск с системой.
- zapret — перенос стратегий Flowseal для Linux: установка одной кнопкой, выбор стратегии, запуск системной службой.
- Cloudflare WARP подключается и отключается с карточки. Happ открывается, подключаться — в его окне.
- Пока VPN подключён, zapret на паузе: вместе они ломают Discord и YouTube.
- Установка программ из Flathub, репозитория системы или официальных выпусков на GitHub с проверкой контрольной суммы.
- Проверка связи с YouTube, Discord, Spotify и Telegram. Обновление AppImage с GitHub.
