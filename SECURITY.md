# Безопасность

## Поддерживаемые версии

Исправления выходят только для последней версии. Старт-пак обновляется сам — кнопка «Обновить» вверху окна.

## Как сообщить об уязвимости

Не создавайте публичный issue. Откройте вкладку **Security → Report a vulnerability** этого репозитория
(приватное сообщение для автора) и опишите:

- что можно сделать и при каких условиях;
- шаги, чтобы повторить;
- версию Старт-пака и Windows.

Ответ — в течение недели.

## Что Старт-пак делает с правами и сетью

- Работает без прав администратора. Права запрашиваются через окно Windows только для действий, которым они нужны:
  запуск и остановка zapret, починка файла hosts для Spotify, снятие драйвера WinDivert при уборке.
- Скачивает только с официальных адресов программ (они перечислены в `src/Installers.cs`) и с GitHub этого проекта.
- Установщики проверяются по цифровой подписи издателя или по SHA-256, опубликованной разработчиком;
  обновления Старт-пака — по SHA-256 из выпуска и по номеру версии внутри файла.
- Ничего не отправляет о вас: ни аналитики, ни учётных записей.
